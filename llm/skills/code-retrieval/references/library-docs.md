# Version-aware library lookup

Use only for an unresolved contract, not routine navigation. Identify the dependency and pinned version from the lockfile, manifest or installed metadata. Distinguish the installed version from a requested upgrade.

Read the relevant installed source or CLI help first. If still unresolved, consult the official documentation for that version. Verify the source URL and content: a version in a search query does not prove a match. Local syntax search cannot establish an external API contract.

Keep the dependency, target version, verified source, relevant contract and remaining uncertainty with the task, not in a permanent file. Reuse that evidence and stop once resolved. If matching evidence is unavailable, report the gap rather than silently relying on memory or another version. Do not send secrets or private source to external searches. No Context7, MCP, credentials or sign-in is required.
